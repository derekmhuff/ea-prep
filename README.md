# EA Prep (self-hosted)

Upload every file in this folder together. The app needs HTTPS for offline mode and "Install app" to work.

## Quickest: Netlify Drop
1. Go to app.netlify.com/drop and sign in (free).
2. Drag this whole folder onto the page.
3. Open the address it gives you on your phone in Chrome, then choose Install app (or Add to Home screen).
4. Optional: in Site settings, rename the site so the address is easy to remember.

To update later, open the site in Netlify, go to Deploys, and drag the updated folder onto it. Your phone picks up the new version the second time you open the app.

## Private alternative: Cloudflare Pages + Cloudflare Access
Cloudflare Pages hosts the folder for free, and Cloudflare Access (free for small teams) can require a one-time email code before anyone can open it.

## Moving your progress
Progress is stored on each device, per web address. To bring progress over:
1. In the old copy, open Progress, then Back up or move your progress, then Show backup code, then Copy code.
2. In the new copy, open the same section, choose Restore from a backup, paste, and select Restore.
Make a backup now and then: clearing Chrome's site data erases the app's progress.
